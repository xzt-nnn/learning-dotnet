## 1.Controller，所有的控制器都继承这个类，这个Controller基类是什么作用？

`Controller`是.NET MVC框架提供的控制器基类，内置`View()`、`Json()`、`Content()`、`RedirectToAction()`、`File()`、`HttpNotFound()`等响应返回方法，自带`Request`、`Response`、`HttpContext`、`Session`、`User`、`RouteData`、`Server`请求上下文，同时支持`ViewData`、`ViewBag`、`TempData`、`ModelState`用于数据传递与模型校验。

## 2 . @Html 是什么

`@`：Razor 语法，**从 HTML 切换到 C# 代码**
`Html`：是 Razor 视图里内置的一个**`IHtmlHelper`类型的对象**，框架自动帮你实例化好，直接在页面用。

IHtmlHelper 是 Razor 视图里的工具对象，专门提供一堆方法，帮你快速生成 HTML 标签、表单、验证信息、链接等，不用自己手写拼接字符串



## 3.批量删除的思路？

不要一条一条去数据库中边查边删，可以一次性将要批量删除的数据查询出来，一次删除即可



## 4.Razor 视图 foreach 循环内，`<td>`中间使用`@* *@`Razor 注释，报 “当前上下文中不存在 item” 的原因



1. Razor 存在两种解析上下文：标记上下文（HTML）、代码上下文（C#）；`<td>`会切换到标记上下文，`@* *@`是 Razor 注释，会切回代码上下文，打断循环块和后续 HTML 标签的从属关系，导致后续拿不到循环变量`item`。
3. 两种注释区别：
- `@* *@`：服务端 Razor 注释，解析时直接删除，**会改变解析上下文，禁止穿插在 HTML 标签中间**
- `<!-- -->`：HTML 注释，下发到浏览器，不影响 Razor 解析，标签之间优先用这个
4. 修复方案：标签之间改用 HTML 注释；Razor 注释放在整块 HTML 前面，不要夹在 HTML 标签中间。
